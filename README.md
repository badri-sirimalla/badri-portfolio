# Badri Sirimalla – Portfolio

Static site (HTML/CSS/JS, no build step, no dependencies).

- Add your resume at `assets/Badri_Sirimalla_Resume.pdf`
- Add certificate URLs in the Certifications section of `index.html` (search for `data-cert-link`), then remove the `pending` class and `aria-disabled` attribute
- Deploy: push to GitHub, then Settings → Pages → deploy from the `main` branch root
